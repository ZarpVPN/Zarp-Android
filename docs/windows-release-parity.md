## Изменения этого этапа

- Настройки → WARP+; также доступно из настроек WARP-эндпоинтов. Чтение типа аккаунта не создаёт регистрацию. Применение ключа при необходимости регистрирует устройство после принятия условий Cloudflare.
- Ключ проверяется до сети, показывается как пароль и не входит в настройки, сохранённое состояние Activity, JSON регистрации или журнал. После успешного PUT без подтверждённого GET показывается «не подтверждено», а не успешная активация.
- Тип подписки определяется явным `account_type`. Неоднозначный флаг `warp_plus` не повышает бесплатный аккаунт до WARP+ и не подтверждает оплату.
- Прямой запрос регистрации выполняется первым. Только сетевой сбой/таймаут разрешает перебор поддерживаемых TLS-стратегий. Сначала выбранная стратегия, затем подтверждённые, затем остальные; фильтр стран и возможности устройства соблюдаются. Чужой VPN и действующее соединение запрещают такой перебор.
- Регистрация, применение ключа и чтение аккаунта после применения используют один защищённый транспорт. Он закрывается при завершении, ошибке и отмене. Редиректы запрещены, сертификат и имя API проверяются. Защищённый режим может использовать [опубликованные адреса Cloudflare API](https://developers.cloudflare.com/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/firewall/#client-orchestration-api), сохраняя проверку TLS по имени.
- Если регистрация выдана, но MASQUE enrollment прервался, приватный `.pending` сохраняет ту же пару ключей и идентификатор. Следующая попытка продолжает enrollment; новые устройства не создаются заново. Рабочая регистрация не перезаписывается. Rate limit, отказ API и ошибка хранилища не запускают перебор.
- WARP+ сериализован с поиском и подключением. Чтение/применение ключа сохраняет активный туннель, выбранную стратегию и результаты. Отмена доступна на странице и через уведомление.
- Быстрый поиск WARP продолжает следующие кандидаты после неудачной повторной проверки. Результаты неудач через чужой VPN не заменяют сохранённые результаты.
- Каждые семь секунд при действующем соединении выполняется один запрос через его SOCKS-прокси с пределом восемь секунд. Сбой при доступном Интернете запускает обычную последовательность восстановления. Без сети сохраняется нативный цикл переподключения и прежние результаты. Задержки Android в фоне и занятый движок могут отложить проверку.
- Девять языков, RTL для فارسی и сохранение LTR у технических полей и журналов. Лицензии включаются в APK из файлов репозитория через generated assets и доступны офлайн.

## Различия платформ

Windows WinDivert/zapret2, его автообновление, MSI, драйверы, служба warp-cli, Defender и трей не переносятся на Android. Их пользовательские задачи выполняются встроенным MASQUE/Go-ядром, VpnService, foreground-уведомлением, APK-подписью и настройкой Android Always-on VPN.

Без root нельзя повторить raw TCP MD5/sequence overlap/hostfakesplit, произвольную IP-фрагментацию и неверные UDP checksum. Они не выдаются за работающий обход. Доступны пользовательские UDP fakes и TCP split/disorder; TTL дополнительно проверяется на устройстве. WireGuard WARP не добавлялся: актуальный Windows-каталог также удалил старые WARP WireGuard-профили.

Неподдерживаемые комбинации серверных ссылок и XHTTP downloadSettings остаются явно отклоняемыми; см. [поддерживаемые подключения](connection-settings.md).

## Проверка

- `gradlew test lint assembleDebug assembleRelease --offline --console=plain` прошёл. 107 JVM-тестов, ноль ошибок. Lint: ноль ошибок и три предупреждения (`OldTargetApi`, `ChromeOsAbiSupport`, `ObsoleteSdkInt`).
- Go: 43 теста верхнего уровня и 41 подтест прошли; `go vet` прошёл. Два пропуска: ручной adb-сервер и платформенный TTL-тест. В числе проверок: настоящее взаимодействие с локальными VLESS, Trojan, Hysteria2 и официальным Xray, а также 24 контракта Kotlin/native.
- Новые тесты: защищённый API-клиент, продолжение enrollment без новой регистрации, ошибки/лимиты, корректный тип аккаунта, отсутствие ключа в конфиге, отмена, приоритеты/фильтры, сохранение активного туннеля при работе с аккаунтом, подтверждённая квота быстрого поиска, чужой VPN, восстановление и отсутствие сети. Проверено, что неподтверждённый успех через чужой VPN не заменяет подтверждённый результат, а медленный фоновый запрос не мешает отключению и не включает отключённый VPN обратно.
- APK содержит `arm64-v8a`, `armeabi-v7a`, `x86_64` и семь файлов лицензий. Debug APK подписан и установлен поверх прежнего без удаления данных; release APK собран без пользовательского release-keystore и остаётся неподписанным.
- Физическое устройство: Huawei ANG-LX1, Android 10, USB ADB. Подтверждены открытие WARP+, чтение реального аккаунта, переключение русского/персидского интерфейса и RTL, маскирование неправильного ключа, запрет его отправки и отсутствие поля после перезапуска. Снимки находятся в локальном `build/`.
- На телефоне QUIC-профиль `warp-q-google6` установил MASQUE за 247 мс, проверка реального WARP-трафика прошла с пингом 169 мс, VPN работает как foreground service. Это результат одного запуска в текущей сети, не гарантия для других провайдеров.
- На финальной сборке проверено 18-секундное отключение Wi-Fi. Wi-Fi автоматически включён обратно через `finally`; WARP восстановился без повторного нажатия, статус снова «Подключено», foreground VPN сохранился. Контрольная проверка показала пинг 206 мс. Снимок: локальный `build/warp-connected-after-recovery-fa.png`.
- Проверка аккаунта при работающем VPN показала бесплатный WARP и сохранила foreground-сервис. На телефоне открыт список всех семи лицензий и текст GPL. После проверки возвращён исходный системный русский язык и отключён тестовый VPN.
- В текущей сети HTTP/2-профиль устанавливает MASQUE, но не проходит проверку DNS/трафика. Для API проверены все пять встроенных TCP-стратегий: `disorder:1,midsld` работает, четыре split-варианта завершаются сетевым таймаутом. Через disorder реально зарегистрировано новое WARP-устройство за 2 026 мс; конфигурация прошла QUIC-подключение и HTTPS-проверку `warp=on`, пинг 174 мс. Первоначальная ошибка прямой сессии для проверки автоперехода была искусственной; прямой API в этой сети доступен. Подробности и границы проверки: [отчёт о новой регистрации](warp-registration-device-check.md).
- Телефону включён `svc power stayon usb`: экран остаётся включённым при питании по USB. Исходное значение `0` записано локально в `build/device-original-stay-on.txt`; отключение USB возвращает обычное засыпание.

Платная активация WARP+ требует действующего пользовательского ключа; в этом этапе ключ не запрашивался и не использовался. Не проверены новый Android API 34+ на физическом устройстве, мобильная сеть, Doze и работа других ABI на реальном оборудовании. Новая реальная WARP-регистрация проверена в отдельном приватном файле: существующая регистрация сохранена.
